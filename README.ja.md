# 自学コーチ

**自学コーチ**（Self-Study Tutor）は、一般的な独学や知識の復習を支援するAI エージェント向けの Skill です。AI チャット内で丁寧な概念解説や学習ガイドを行うとともに、必要に応じて連携 Web アプリ（[aiskillonline.com](https://www.aiskillonline.com)）を活用し、学習アンケート、アニメーション付きホワイトボード、クイズを提供します。目標、希望する言語、これまでの経験を伝えてください。学習のペースと次に学ぶ内容は自分で選べます。

## インストールと動作環境

以下の標準コマンドを実行してスキルをインストールします：

```bash
npx skills add yisi-ai/selfstudy-coach-skill --skill selfstudy-coach
```

- **対象エージェントの選択**: コマンド実行時に、利用する AI エージェントを選択します。
- **導入スコープ**: デフォルトでは現在のプロジェクト配下に導入されます。`--global` フラグを付与するとグローバル環境にインストールされます。
- **公式リファレンス**: 詳細なオプションについては [Skills CLI インストールドキュメント](https://github.com/vercel-labs/skills#install-a-skill) をご参照ください。
- **呼び出し方法**: チャット内で `$selfstudy-coach` と入力して呼び出します。

### 動作環境の要件

- **CLI のインストールと管理**: ローカル環境に Node.js および npm が必要です。
- **ローカル連携ブリッジの確立**: チャット環境から直接 Web アプリへローカル接続を行う場合は、**Node.js 22+** が必要です。
- **ブラウザでの直接利用**: ブラウザ上で直接 Web アプリを開いて手動操作する場合は、ローカルの Node.js は不要です。

> **アップデート時の注意**: 更新前に、インストール済みの Skill をバックアップし、カスタマイズ内容を保管してください。エージェントに手伝ってもらうこともできます。更新コマンドによる自動マージには頼らないでください。

## 主な学習シナリオ例

次のように話しかけて学習を始められます：

### 1. 自学プランの作成

```text
$selfstudy-coach これから2か月で、機械学習に必要な線形代数を基礎から独学したいです。週ごとの学習計画を立て、短いアンケートで私の経験と目標を確認してから、最初の課題を提案してください。
```

### 2. 難解な概念の集中解説

```text
$selfstudy-coach JavaScript の「クロージャ（Closure）」がうまく腑に落ちません。身近な例えを用いて段階的に解説し、ホワイトボードでスコープとメモリの動きを見せてください。
```

### 3. ノートの理解度テスト・復習

```text
$selfstudy-coach 今日読んだミクロ経済学の「需要と供給の弾力性」のまとめノートを共有します。重要なポイントについて私にクイズを出題し、理解が曖昧な部分を指摘してください。
```

## 連携 Web アプリとの協調動作

本スキルは、必要に応じて Web アプリ [https://www.aiskillonline.com](https://www.aiskillonline.com) と連携します：

- **学習アンケート**: 採点のない質問で、目標、経験、困っていることを伝えられます。
- **アニメーション付きホワイトボード**: 2D・3D の図解で過程や関係を確認し、各段階を再生したり、わからない箇所に印を付けたりできます。
- **クイズ**: 単一選択・複数選択の問題に自分で答えます。エージェントは実際の回答をもとに間違いを解説し、復習を手伝います。

### 接続方法

エージェントは最初の学習応答時に接続を準備し、次の順で利用できる方法を選びます。接続後はエージェントが教材の準備と結果の読み取りを行い、あなたがアンケートやクイズに回答します。

1. **ローカル Node.js 22+ による直接接続**: サイドバーまたは標準ブラウザと直接連動。
2. **ブラウザ自動化ツール**: 実際に表示されている画面を直接操作できるブラウザ統合。
3. **手動データ引き渡し**: JSON ファイルやコードブロックを受け取り、Web アプリにインポートまたは貼り付け。

*補足*: ローカル待機サービスは一度起動すると、ブラウザのタブを閉じてもバックグラウンドで待機を継続します。停止させたい場合はチャット上で明示的に停止を指示してください。

## データ境界と学習継続の仕組み

- **学習データの保存場所**: 解答履歴や学習ライブラリは、実際にクイズを解いたブラウザのローカル領域に保存されます。端末間の自動同期機能は提供していません。
- **元データ（写真など）の扱い**: 元のノート写真はチャット内に残ります。そこから作成したクイズやホワイトボードなどの学習コンテンツを Web アプリに渡します。
- **次回への引き継ぎ**: 学習計画や進捗のサマリーはチャット履歴内に残ります。新しいチャットを開始する際は、直前の学習サマリーを貼り付けることで、前回の続きから学習を再開できます。
