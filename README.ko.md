# 자기주도 학습 코치

**자기주도 학습 코치**(Self-Study Tutor)는 폭넓은 자율 학습과 체계적인 복습을 돕는 AI 에이전트용 Skill입니다. 대화형 AI 인터페이스에서 개념을 단계별로 설명하고 학습을 이끌어주며, 필요 시 전용 웹 애플리케이션([aiskillonline.com](https://www.aiskillonline.com))과 연동하여 학습 설문, 애니메이션 화이트보드, 퀴즈를 제공합니다. 목표와 선호하는 언어, 현재 알고 있는 내용을 알려주세요. 학습 속도와 다음에 배울 내용은 직접 선택할 수 있습니다.

## 설치 및 환경 설정

표준 명령어를 사용하여 본 스킬을 설치합니다:

```bash
npx skills add yisi-ai/selfstudy-coach-skill --skill selfstudy-coach
```

- **대상 Agent 선택**: 설치 명령어 실행 시 안내에 따라 사용할 AI 에이전트를 선택합니다.
- **설치 범위**: 기본적으로 현재 프로젝트 폴더에 설치되며, `--global` 플래그를 추가하면 전체 환경에 전역 설치됩니다.
- **공식 문서**: 상세 옵션은 [Skills CLI 설치 공식 문서](https://github.com/vercel-labs/skills#install-a-skill)를 참고하세요.
- **호출 방법**: 대화창에서 `$selfstudy-coach`를 입력하여 코칭을 시작합니다.

### 실행 환경 구분

- **CLI 설치 및 관리**: 로컬 환경에 Node.js 및 npm이 필요합니다.
- **로컬 직접 연결**: 로컬 대화 환경과 웹 앱을 직접 브리지로 연결하려면 **Node.js 22+** 가 필요합니다.
- **브라우저 직접 사용**: 웹 브라우저에서 직접 웹사이트를 방문하여 수동으로 사용할 때는 로컬 Node.js 설치가 필요하지 않습니다.

> **업데이트 주의사항**: 업데이트 전에 설치된 Skill을 백업하고 직접 수정한 내용을 보관하세요. 에이전트에게 도움을 요청할 수 있습니다. 업데이트 명령이 수정 사항을 자동으로 병합해 줄 것이라고 가정하지 마세요.

## 핵심 학습 시나리오 예시

다음과 같이 대화를 시작해 보세요:

### 1. 자기주도 학습 계획 수립

```text
$selfstudy-coach 앞으로 2달 동안 머신러닝에 필요한 선형대수학을 기초부터 독학하려고 합니다. 주차별 학습 계획을 세우고, 짧은 설문으로 제 경험과 목표를 확인한 뒤 첫 학습 과제를 제안해 주세요.
```

### 2. 난해한 핵심 개념 돌파

```text
$selfstudy-coach 자바스크립트의 '클로저(Closure)' 개념이 명확하게 와닿지 않습니다. 일상적인 비유를 들어 단계별로 설명해 주고, 화이트보드로 스코프와 메모리 흐름을 보여주세요.
```

### 3. 개인 노트 기반 복습 및 퀴즈

```text
$selfstudy-coach 오늘 공부한 미시경제학 '수요와 공급의 탄력성' 요약 노트입니다. 핵심 내용으로 저에게 퀴즈를 내어 이해도를 점검하고, 부족한 개념을 짚어주세요.
```

## 전용 웹 애플리케이션 연동 방식

본 스킬은 필요에 따라 전용 웹 서비스인 [https://www.aiskillonline.com](https://www.aiskillonline.com)과 협업합니다:

- **학습 설문**: 점수를 매기지 않는 질문으로 목표, 경험, 어려운 점을 전달합니다.
- **애니메이션 화이트보드**: 2D·3D 설명으로 과정과 관계를 살펴보고, 각 단계를 다시 재생하거나 이해되지 않는 부분을 표시할 수 있습니다.
- **퀴즈**: 단일 선택형과 복수 선택형 문제에 직접 답합니다. 에이전트는 실제 답변을 바탕으로 오답을 설명하고 복습을 돕습니다.

### 연결 방법

에이전트는 첫 학습 응답에서 연결을 준비하고 아래 순서로 사용 가능한 방법을 선택합니다. 연결되면 에이전트가 학습 활동을 준비하고 결과를 읽으며, 사용자는 설문과 퀴즈에 직접 답합니다.

1. **로컬 Node.js 22+ 연결**: 사이드바 또는 시스템 브라우저와 로컬 브리지로 직접 연동.
2. **브라우저 도구 제어**: 실제로 답하는 웹페이지를 직접 제어할 수 있는 브라우저 도구 사용.
3. **수동 데이터 전달**: JSON 파일이나 코드 블록을 받아 웹 앱으로 가져오거나 붙여넣기.

*참고*: 로컬 서비스가 시작되면 브라우저 탭을 닫더라도 백그라운드에서 계속 대기 상태를 유지합니다. 서비스를 끄려면 대화창에서 명시적으로 종료를 요청해야 합니다.

## 데이터 경계 및 학습 이어가기

- **학습 라이브러리 저장 위치**: 퀴즈 결과 및 학습 라이브러리는 실제로 풀이를 완료한 브라우저의 로컬 저장소에 보관됩니다. 기기 간 자동 동기화 기능은 제공되지 않습니다.
- **원본 자료 처리**: 원본 필기 사진은 대화에 남습니다. 이를 바탕으로 만든 퀴즈나 화이트보드 등의 학습 콘텐츠를 웹 앱에 전달합니다.
- **세션 이어가기**: 학습 계획과 진행 요약은 대화 기록에 남습니다. 새로운 대화를 시작할 때는 이전 대화 마지막에 생성된 학습 요약을 새 대화로 복사해 전달하면 코치가 이전 진행 상황을 파악하고 학습을 이어갈 수 있습니다.
