# 自学教练

**自学教练**（Self-Study Tutor）是一个帮助你自学和复习的 AI Agent Skill。它在 AI 对话界面中为你提供循序渐进的引导与概念拆解，并在需要深入练习时联动配套网页（[aiskillonline.com](https://www.aiskillonline.com)），通过学习问卷、动画白板与测验帮助你理解和练习。告诉它你的目标、偏好的语言和已有基础，学习节奏与下一步方向由你决定。

## 安装与环境依赖

使用标准命令安装本技能：

```bash
npx skills add yisi-ai/selfstudy-coach-skill --skill selfstudy-coach
```

- **选择目标 Agent**：执行安装命令时，根据终端提示选择你使用的 AI Agent。
- **安装范围**：默认安装在当前项目目录下；添加 `--global` 参数可进行全局安装。
- **官方参考**：更多 CLI 参数与安装细节请参阅 [Skills CLI 安装文档](https://github.com/vercel-labs/skills#install-a-skill)。
- **调用方式**：在对话中使用 `$selfstudy-coach` 开始学习。

### 环境要求区分

- **CLI 安装与管理**：需要本地安装 Node.js 与 npm 环境。
- **建立本机直接连接**：如果需要本地对话与配套网页建立联动通道，需要本地环境具备 **Node.js 22+**。
- **直接浏览器使用**：若通过浏览器直接手动访问并操作配套网页，无需在本地安装 Node.js。

> **版本更新提示**：更新前，请备份已安装的 Skill 并保留自己的定制改动。可以请 Agent 协助，不要依赖更新命令自动合并你的修改。

## 核心学习场景示例

可以这样开始对话：

### 1. 制定自学规划

```text
$selfstudy-coach 我打算利用两个月时间从零自学机器学习所需的线性代数。请帮我拆解每周学习路线，先用简短问卷了解我的基础和目标，并给出第一阶段的起步任务。
```

### 2. 难点概念攻坚

```text
$selfstudy-coach 我对 JavaScript 中的“闭包”（Closure）概念一直理解不透彻。请用直观的生活比喻分步拆解它的运行过程，并在白板上展示内存与作用域的变化。
```

### 3. 笔记检测复习

```text
$selfstudy-coach 这是我今天阅读微观经济学“供求弹性”一节记下的笔记。请根据笔记重点向我提问，测试我的掌握程度，并指出我可能遗漏的关键逻辑。
```

## 配套网页协作机制

本技能按需与配套服务 [https://www.aiskillonline.com](https://www.aiskillonline.com) 协同工作：

- **学习问卷**：通过不计分的问题，了解你的目标、已有基础和困难。
- **动画白板**：用二维或三维演示解释过程和关系，支持分步回放和标记不理解的步骤。
- **测验**：由你亲自回答单选和多选题，Agent 根据实际答案解释错误并帮助复习。

### 如何连接

Agent 会在第一次学习回复时准备连接，按以下顺序选择可用方式。连接成功后，它负责准备活动和读取结果，你负责填写问卷与回答测验。

1. **本机 Node.js 22+ 联动**：通过本地端口与侧栏或系统浏览器直接联动；
2. **浏览器工具控制**：借助 Agent 能够直接控制的可视化网页浏览器工具；
3. **手动交接数据**：提供 JSON 文件或代码块，由你导入或粘贴到网页。

*说明*：当本地服务成功启动后，即使关闭浏览器标签页，该服务仍会在后台保持待机，直到你在对话中明确要求停止。

## 数据边界与续学机制

- **学习库存储位置**：测验记录与学习库保存在你实际完成作答的浏览器本地存储中，不会自动跨设备同步。
- **原始材料处理**：你的原始笔记照片留在对话中；由此生成的测验、白板等学习内容交给配套网页。
- **跨对话续学**：当前学习计划与阶段进展摘要保存在对话记录中。开启新对话时，将上一轮结束时生成的续学摘要复制发送给新对话，让教练了解已有进展后继续学习。
