# 自學教練

**自學教練**（Self-Study Tutor）是一個協助你自學與複習的 AI Agent Skill。它在 AI 對話介面中為你提供循序漸進的引導與觀念拆解，並在需要時搭配配套網頁（[aiskillonline.com](https://www.aiskillonline.com)），透過學習問卷、動畫白板與測驗協助你理解和練習。告訴它你的目標、偏好的語言與已有基礎，學習步調和下一步方向由你決定。

## 安裝與環境依賴

使用標準指令安裝本技能：

```bash
npx skills add yisi-ai/selfstudy-coach-skill --skill selfstudy-coach
```

- **選擇目標 Agent**：執行安裝指令時，依終端提示選擇你使用的 AI Agent。
- **安裝範圍**：預設安裝在當前專案目錄；加上 `--global` 參數即可進行全域安裝。
- **官方文件**：更多 CLI 參數與設定細節請參閱 [Skills CLI 安裝文件](https://github.com/vercel-labs/skills#install-a-skill)。
- **呼叫方式**：在對話中輸入 `$selfstudy-coach` 即可啟用自學教練。

### 環境需求說明

- **CLI 安裝與管理**：本機需具備 Node.js 與 npm 環境。
- **建立本機直連通道**：若需要本機環境與配套網頁建立直接連動，需安裝 **Node.js 22+**。
- **瀏覽器手動操作**：若僅透過瀏覽器手動瀏覽並使用配套網頁功能，不需要在本機安裝 Node.js。

> **版本更新提醒**：更新前，請備份已安裝的 Skill 並保留自己的客製化修改。可以請 Agent 協助，不要依賴更新指令自動合併你的改動。

## 核心學習場景範例

你可以直接複製以下範例在對話中開始學習：

### 1. 制定自學規劃

```text
$selfstudy-coach 我打算利用兩個月時間自學機器學習所需的線性代數。請幫我規劃每週進度路線，先用簡短問卷了解我的基礎與目標，並給出第一週的學習任務。
```

### 2. 難點觀念攻堅

```text
$selfstudy-coach 我對 JavaScript 的「閉包」（Closure）機制一直無法完全釐清。請用清楚的生活比喻逐步拆解，並在白板上呈現作用域與記憶體的互動關係。
```

### 3. 筆記檢測複習

```text
$selfstudy-coach 這是我今天研讀個體經濟學「供需彈性」整理的筆記重點。請針對關鍵概念對我進行抽考提問，檢視我的理解程度並點出盲點。
```

## 配套網頁協作機制

本技能依學習需求與配套服務 [https://www.aiskillonline.com](https://www.aiskillonline.com) 協同運作：

- **學習問卷**：透過不計分的問題，了解你的目標、已有基礎與困難。
- **動畫白板**：用二維或三維示範解釋過程與關係，支援分段重播及標記不理解的步驟。
- **測驗**：由你親自回答單選與多選題，Agent 根據實際答案解釋錯誤並協助複習。

### 如何連線

Agent 會在第一次學習回覆時準備連線，依以下順序選擇可用方式。連線成功後，它負責準備活動和讀取結果，你負責填寫問卷與回答測驗。

1. **本機 Node.js 22+ 連線**：直接與側邊欄或系統瀏覽器進行雙向連動；
2. **瀏覽器自動化工具**：透過能直接控制你實際作答網頁的瀏覽器工具；
3. **手動資料交接**：提供 JSON 檔案或程式碼區塊，由你匯入或貼上至網頁。

*注意事項*：本機服務一旦啟動，即使關閉瀏覽器分頁也會在背景保持待命狀態，直到你在對話中明確指示關閉。

## 資料邊界與延續學習機制

- **學習庫儲存範圍**：測驗紀錄與個人學習庫保存在你實際完成測驗的瀏覽器本機端，本專案不提供跨裝置自動同步。
- **原始素材處理方式**：你的原始筆記照片留在對話中；由此產生的測驗、白板等學習內容交給配套網頁。
- **跨對話接續學習**：學習計畫與接續摘要保留在對話中。開啟新對話時，請將上一輪結束時產生的續學摘要帶入新對話，讓教練了解已有進展後繼續學習。
