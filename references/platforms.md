# 三端入口与数据范围

Skill 操作版本 0.4.25。Web、Chrome 扩展和微信小程序复用同一题集、作答和问卷规则，各端资料独立保存在本机。首次三题体验只保存在内存；正式自学入门题集三端使用同一版本。

## 选择用户实际使用的端

- Web：继续使用现有浏览器命令 `window.studyWeb.execute(request)` 或学习本机连接。连接脚本只服务 Web；当前回答以实际答题浏览器为准。
- Chrome 扩展：在已打开的扩展侧栏页面上下文调用 `window.studyWeb.execute(request)`，先调用 `version`、`help` 核验。不能在普通网站标签页调用并假设它访问扩展资料。图片通过 HTTPS 网址直接显示，不增加 host_permissions；侧栏没有 Web 的 localhost 连接服务。
- 微信小程序：通过已连接的微信 IDE 运行时调用 `getApp().executeStudyCommand(request)`，先调用 `version`、`help`。运行时不可用时，交付共同 JSON，让用户从小程序导入页导入；完成问卷后可复制回答交回 AI。不把 IDE 命令可用当作手机自动连接可用。

三端命令包括 `quiz.import/list/search/open/start/attempts/result`、`question.search/read`、`questionnaire.import/read/open` 和 `snapshot.read`。导入测验默认中等模式并打开第一题；继续作答保留现有选择、难度和截止时间。Agent 不替用户选答案。问卷独立保留当前一份；新问卷替换当前缓存，不计分，不写题库或成绩。

写命令携带稳定 `requestId`。直接运行时入口在当前进程内去重；Web 学习本机连接另有跨刷新回执。扩展侧栏或微信进程重启后，若前次结果不明确，先查询已保存资料，不能自动重放导入。读取命令不修改资料。`snapshot.read` 保留普通/混合选择，问卷单独返回；它不是完整学习备份文件。

## 当前交付格式

默认生成文字 `gaga.quiz` v1 或 `gaga.questionnaire` v1。需要公式、图形或图片且目标端操作版本支持时，可生成 `gaga.quiz` v2，具体字段见 [图文题集](quiz-format.md#三端图文题集)。正式备份是 `gaga.quiz.backup` v3（可读 v1/v2），包含题集、每题最近对错和时间、未完成普通进度。混合练习回写原题集，不单独保存已完成混合历史；问卷及未完成混合会话不在普通备份文件内。

三端正式流程支持公式 LaTeX 原文、参数化几何图形及动画、HTTPS 图片网址。题干、选项和解析均可带图文，普通备份完整保留这些字段。图片只保存网址和说明，不保存图片文件；断网或链接失效时可能无法显示图片。Web/Chrome 的导入预览、普通及混合练习、即时解析、结果回顾和题集详情共用图文显示组件；导入与恢复在写入前预检公式能力，未知能力不会静默丢失。候选 ZIP 媒体包及图片离线归档不启用。源码接入不代表旧版已发布客户端支持，自动导入前先核对 Skill 操作版本，手机显示仍需真机验收。

三端醒目提示资料仅保存在本地。Web 改用 IndexedDB，Chrome 增加 unlimitedStorage 权限，均不设题库人为容量或数量上限；宿主写入失败仍明确提示存储已满。小程序按全部本地业务数据的实际总占用和宿主上限更新剩余量，达到 80% 提醒，点击查看说明。每题只保存最近对错和判定时间，混合回写来源，删除题集同时删除记录；不新增错题集功能，可用 question.search 的 correct: false 查询。

Web/Chrome 手动新增页点击“读取剪贴板”后自动校验并导入，无题集文本框、文件入口和预览确认；错误以弹窗显示。小程序保留原有预览确认。Web/Chrome 独立备份恢复仍提供文件/文本输入和确认，Agent 命令入口不变。
